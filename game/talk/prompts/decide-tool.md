# The call the action track must make. Its schema is the menu, so the only
# answer that can come back is a line that was on it.
name: report_action
description: Report what {{name}} does as this exchange ends, as the number of the line on the list, and how {{name}}'s own reply came down. 1 is nothing but talk, and it is almost always 1.
option: The number of the line on the list. 1 for nothing but talk.
answer: How {{name}}'s own reply came down: yes if they went along with what was put to them, no if they would not or could not, neither for everything else, which is most replies. Never the other person's answer.
